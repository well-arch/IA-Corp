L'assistant répond à vos questions, résume et reformule des textes, traduit et analyse les
documents que vous lui donnez. Il fonctionne sur les serveurs de l'entreprise : vos
échanges ne sont pas envoyés à un service d'IA externe.

## Première connexion

**Il vous faut :** un compte autorisé pour l'assistant, votre mot de passe Windows et une
application d'authentification sur votre téléphone : `[À COMPLÉTER : application conseillée]`.

1. Sur le réseau de l'entreprise, ouvrez `[À COMPLÉTER : https://assistant.exemple.local]`.
2. Cliquez sur **Compte entreprise**.
3. Saisissez votre identifiant et votre mot de passe Windows.
4. Scannez le QR code affiché avec votre application d'authentification.
5. Saisissez le code à 6 chiffres affiché par l'application, puis validez.

Aux connexions suivantes, le mot de passe et le code suffisent. Sans activité, ou au plus
tard après quelques heures, il faudra vous reconnecter : c'est normal.

## Bien utiliser l'assistant

- **Donnez le contexte :** le destinataire, le but, le format et la longueur voulus.
- **Vérifiez toujours le résultat :** il peut se tromper avec beaucoup d'assurance, surtout
  sur les chiffres, les dates, les noms et les références juridiques. Vous restez
  responsable de ce que vous en faites.
- **Pour un document :** ajoutez-le à la conversation, puis demandez de citer les passages
  utilisés, et contrôlez-les dans l'original.
- **Relancez :** « plus court », « sur un ton plus formel », « explique ton raisonnement ».

Exemple : *« Résume ce compte rendu en 5 points pour un directeur qui n'y était pas, puis
liste les décisions et leurs responsables. »*

### Ce qu'il ne fait pas aujourd'hui

- Il **ne lit pas** vos mails, votre agenda ni les partages réseau, et n'envoie rien en
  votre nom.
- Il **n'a pas accès à Internet** : il ne connaît pas l'actualité récente.
- Il ne connaît que ce que vous lui donnez dans la conversation, et les bases documentaires
  ouvertes à votre service, le cas échéant.

## Règles à respecter

**Interdit :**

- Trier des candidatures, évaluer ou classer des personnes.
- Prendre une décision sur une personne (RH, disciplinaire, médicale) à partir de ses réponses.
- Saisir des mots de passe ou d'autres identifiants.

**À demander d'abord à votre responsable ou au DPO :** données de santé, données sensibles
sur des personnes, documents classés confidentiels :
`[À COMPLÉTER : règles selon la charte]`.

**Méfiance avec les documents reçus de l'extérieur :** un fichier peut contenir des consignes
cachées destinées à l'IA. Si la réponse semble étrange ou vous pousse à une action
inhabituelle, ne la suivez pas et signalez-la.

## En cas de problème

| Situation | Que faire |
|---|---|
| Page inaccessible ou alerte de sécurité dans le navigateur | Vérifiez que vous êtes sur le réseau de l'entreprise ou le VPN. Si l'alerte persiste, **ne la contournez pas** : contactez le support |
| Mot de passe refusé | Vérifiez-le sur votre session Windows. Il se change comme d'habitude, jamais dans l'assistant |
| Compte bloqué après plusieurs échecs | Attendez quelques minutes, puis réessayez |
| Téléphone perdu ou changé, code refusé | Contactez le support, qui réinitialise votre authentification. En cas de perte, faites-le sans attendre |
| « Accès en attente » ou refusé | Votre compte n'est sans doute pas encore autorisé : contactez votre responsable ou le support |
| Réponses lentes | L'heure de pointe peut allonger l'attente. Si cela dure, signalez-le |
| Réponse fausse ou inquiétante | Signalez-la, avec si possible la conversation |
| Document sensible envoyé par erreur | Contactez immédiatement le support et le DPO |
